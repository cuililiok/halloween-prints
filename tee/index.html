按生活场景开款，不是按克重开款。三条轨： 日常 T · 简约基础（通勤、约会、周末出门）用领型、小标、口袋、明线拉开货盘； 亨利衫 · 领型结构（长袖亨利、棉麻亨利、户外休闲亨利）单独成盘，主图必须拍出 2–3 粒扣，走亨利衫免审路径； 健身运动 T · 速干 / 弹力（训练、跑步、健身房）卖排汗和贴身。重磅、华夫格放面料模块。

选品 · 四模块开款 · 给商家的提炼

开款优先级 日常先开净色圆领，再补 V 领 / 小标 / 拼色领 / 口袋；结构测半拉链和明线宽松。运动单独开速干 + 弹力。重磅、华夫格是面料，不放进场景盘。
走量 vs 溢价 走量看版型稳定与复购色；溢价不要靠大印花，靠克重数字、纱线名（匹马 / 双纱）、肌理近景、洗水缸差说明。
面料怎么写 标题写清克重（260gsm / 7.6oz）。差评高频：缩水、透、领口松、起球。预缩 + 双针领是基础款生命线。
运动款单独成盘 速干 / 压缩不要和重磅纯棉共用主图。功能款卖弹力与排汗，基础款卖手感和版型，两套话术不要混。
洗水是工艺不是图案 酸洗、成衣染、扎染按「每件略有差异」写详情。破洞克制。300gsm+ 酸洗空白 Tee 是当前跟款热点。
设计点到为止 拼接看缝位，刺绣看 3–5cm 小标。万圣节等节日印花只做 6–8 周爆发，不做全年主 SKU。避开潮牌 / 球星 / 动漫原图。
产品结构 流量 $8–16 基础色 → 利润 $14–28 重磅 / 肌理 / 洗水 → 高客单 $22–45 匹马棉 / 刺绣 / 独立站对标。
美 vs 欧 美站可更宽、更洗、更重；欧站同版型换干净配色，克重话术保留。英区检索用 t-shirt / washed tee。
独立站对标 看 Buck Mason 三条面料轨、Uniqlo U 宽版 $20、Comfort Colors 成衣染。抄结构，不要抄 Logo。
亨利领单独开 两条亨利衫路径都要扣位结构。主图看不到 2–3 粒扣，就不要挂亨利衫。棉麻亨利走度假色。
